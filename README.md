# Interiors by Uyi

A one-page furniture website for **Interiors by Uyi**, a furniture brand based in Benin City, Nigeria.

## About

This is a clean, responsive, single-page website built with plain HTML5 and CSS3. No JavaScript, no frameworks, no build tools. It opens directly in any browser from the file system.

The design aims for a warm, personal, boutique-furniture feel — not a generic template.

## Files

```
index.html    — The full one-page website
style.css     — All styles (CSS variables, Grid, Flexbox, media queries)
README.md     — This file
```

## How to View

Open `index.html` in any web browser. No server needed.

## Technical Details

- **HTML5** with semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** with custom properties, CSS Grid, Flexbox, and media queries
- **No JavaScript** — everything works without scripts
- **Responsive** — tested at desktop (1280px), tablet (~900px), and mobile (~390px)
- **Fonts** — Playfair Display (headings) and DM Sans (body) via Google Fonts
- **Colours** — warm cream, sand, walnut brown, charcoal, terracotta, muted brass
- **Images** — sourced from image search; all are used as editorial/inspirational references

## Prices

All prices are editable estimates in Nigerian Naira (₦). They appear as "Starting from" prices in the Collections section and as "From ₦X" in the Featured Pieces section. To update a price, search for the ₦ symbol in `index.html`.

## How to Edit

The site is designed to be easily editable:

- **Text content** — Edit directly in `index.html`. All sections are clearly commented.
- **Images** — Replace `src` URLs in `<img>` tags with your own image URLs or local file paths.
- **Prices** — Search for `₦` in the HTML to find and update all prices.
- **Colours** — Change the CSS custom properties at the top of `style.css` (`:root` block).
- **Fonts** — Swap the Google Fonts link in `index.html` and update `--font-heading` / `--font-body` in `style.css`.
- **Contact details** — Search for the phone number, email, or TikTok URL to update.
